# Grow My Therapy – Frontend Developer Assignment

## 🎯 Project Overview

This project is a two-stage frontend development and design assignment for Grow My Therapy. It demonstrates the ability to transition from a precise UI clone to a customized, high-end professional brand for a mental health professional.

- **Stage 1**: Precise structural and layout clone of the "Lilac" Squarespace template.
- **Stage 2**: Creative redesign and rebranding for **Dr. Maya Reynolds, PsyD**, a Santa Monica-based therapist.

## 🚀 Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel

## ✨ Features & Implementation

### 1. UI Cloning Accuracy

- Replicated the original grid systems, spacing, and hierarchy of the Lilac template.
- Implemented full mobile responsiveness across all viewports.
- Used reusable Tailwind components to ensure structural integrity.

### 2. Strategic Redesign (Dr. Maya Reynolds)

- **Brand Identity**: Shifted from "Lilac" to an "Anti-Gravity" minimalist white theme to appeal to high-achieving professionals.
- **SEO Optimization**: Every headline and bio is derived from Dr. Maya Reynolds’ profile, optimized for high-ranking local SEO in Santa Monica, CA.
- **Visuals**: Replaced stock images with professional headshots and high-quality office photography.

### 3. Custom "Our Office" Section

- Created a completely new section titled **"A Space for Healing"**.
- Highlights Dr. Maya's physical practice space to build trust and encourage in-person bookings.
- Matches the "warm, collaborative, and grounded" tone of the overall brand.

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Punyashreekm/Grow-My-Therapy
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Run the development server**:
   ```bash
   npm run dev
   ```
